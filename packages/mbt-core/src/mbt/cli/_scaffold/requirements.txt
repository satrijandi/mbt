# Pinned install set for the reference CI workflows (.github/workflows/*.yml).
# A floating training environment invalidates the manifest's env digest, so CI
# always installs from this file, never from bare package names.
#
# These git refs pin mbt to an immutable release tag: reproducible AND
# installable straight from a fresh checkout, with no private index required.
# They resolve once the matching vX.Y.Z tag exists on the mbt repo - the repo's
# release.yml builds that tag's wheels and (once configured) publishes them to
# PyPI at the same time.
#
# Once mbt is on PyPI, switch to plain version pins (mbt-core==X.Y.Z) and, for a
# fully transitively pinned, hash-verified lock, run:
#   uv pip compile --generate-hashes requirements.in -o requirements.txt
